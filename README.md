## 我在踩的坑（真实记录）

| 错误 | 学到什么 |
|---|---|
| `print` 打成 `price` → `TypeError` | 拼错变量名，可能撞上另一个真实存在的名字 |
| `"8.8" * "8"` → `TypeError` | `*` 的含义取决于两边类型 |
| `float("abc")` → `ValueError` | 类型对但值不行 |
| `policy["model"]` 少个 s → `KeyError` | 字典的 key 必须完全一致 |
| 死分支：`cost > 50` 永远走不到 | 条件顺序会静默改变行为 |
| 改了判断没改显示 | 同一个事实不能在两处分别计算 |
| `0.1 + 0.2 ≠ 0.3` | 浮点数不能算钱，要用"分" |
